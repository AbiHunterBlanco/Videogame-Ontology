# 🎮 Ontology Game Explorer

A video game ontology explorer with **recommendations that explain themselves**. It was built as my MSci final-year project: an OWL ontology of the games domain, served through a REST API, with a deliberately transparent recommender on top.

> Instead of "because you liked X" and a black-box score, every suggestion shows the ontology relations that produced it: *"Shares genre: Action, Shooter · Marked similar to Helldivers"*.
